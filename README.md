# Industrial Defect Detection System

End-to-end industrial visual inspection project based on YOLO and OpenCV.

## Project Goal

Build a practical industrial defect detection pipeline covering:

- dataset inspection
- image preprocessing
- YOLO training
- model evaluation
- false-positive / false-negative analysis
- ONNX deployment
- visualization demo

## Tech Stack

Python / PyTorch / YOLO / OpenCV / ONNX
